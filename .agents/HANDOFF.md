0. **Дзвінок бере рівень платформи (13.10, #1704 BitPerfect):** `698830f` — без власної пам'яті
   дзвінка (зсув 6→10 при пробудженні ковтав resync). На стенді з 13.10 19:13, живим дзвінком не перевірено. Перевірка:
   `setprop sys.call.vol 10` поза дзвінком → дзвінок → лишається 10.
0b. **Гучність джерел (12.10, #1672/#1673):** `4d1006d` — пам'ять wDSP переймає зміни рівня
   дзвінка/радіо/AUX/медіа ззовні (`SourceLevelWatch`), на дзвінку без GALA. Стоїть на стенді,
   перевірено setprop-ами. **Лишилось:** живий дзвінок власника (10 у «Налаштуваннях авто» → гудок
   на 10). Камера заднього ходу джерело на 0 не скидає (перевірено з власником 23:27: радіо 0
   лишилось 0). Пробудження з ACC OFF не перевірено: якщо там 0 → main_volume, wDSP перейме
   це як зміну користувача (повернення на 3 замість 1) — власник вирішує, чи це вада.
0a. **Сервіс на подіях (12.10, `46a717d`, `05dd980`):** тіку нема, перевірку будять властивості
   (`__system_property_wait` + фільтр значень), бродкасти, сесії, сигнал, GPS; таймер — лише GALA
