## 1. Резюме (Executive Summary)

1. **Сабвуферний кросовер підключений ПІСЛЯ 16-смугового EQ**:
   - 🔬 У прошивці `002121` регістр селектора `0206` (**DSP Selector 4**) має жорстке значення **`0x00`**.
   - Біти `[7:6]` (`SL X'over Input Selector`) встановлені в **`00` = `Time Alignment`**.
   - За внутрішньою топологією BU32107 (datasheet pp. 88–90) блок Time Alignment розташований **після 16-смугового параметричного EQ (`0610`..`061F`) та P2Bass (`0705`..`0706`)**.
2. **Маршрутизація виходу на фейдер**:
   - 🔬 Регістр `0102` (**Fader Input Selector**) має жорстке значення **`0x00`**.
   - Біти `[5:4]` (`Sub Selector`) встановлені в **`00` = `SL / SR`** (вхід сабвуферного фейдера живиться від каналів кросовера сабвуфера DSP).
3. **Незмінність у рантаймі**:
   - Жодна серійна команда MCU (`0x80`, `0x88`, `0x89`, `0x8A`, `0x8B`, `0x8C`) ніколи не модифікує регістри `0102` та `0206`. Вони перманентно утримуються в значенні `0x00` фоновим циклом синхронізації MCU `FUN_08004E64`.
4. **Практичний висновок для динамічної тонкомпенсації (Dynamic Loudness)**:
   - 🧩 **Підтверджено гіпотезу Claude**: Будь-який підйом низьких частот еквалайзером (20, 31.5, 50, 80 Гц) **на 100% потрапляє в сабвуферний канал**.
   - Додатковий підйом параметра "Subwoofer gain" у тій самій смузі створює **подвійне підсилення басу**. Компенсацію кривої ISO 226 слід здійснювати через еквалайзер, а гейн сабвуфера додавати лише тоді, коли вичерпано динамічний діапазон смуг EQ (+12 дБ).

## 2. Точний побітний розбір регістрів

### 2.1. Регістр `0206` (Select Address `0x0206` / DSP Selector 4)
* **Розташування в Flash таблиці мапінгу**: `0x0800D02D` (індекс `43` у таблиці `0x0800CFD7`).
* **Адреса в SRAM тіньовому буфері**: `0x200000E2 + 43 = 0x2000010D`.
* **Значення в прошивці**: **`0x00` (`00000000b`)**.

| Біти | Поле | Значення | Розшифровка за даташитом BU32107 |
|:---:|:---|:---:|:---|
| **[7:6]** | **SL X'over Input Selector** | **`00`** | **Time Alignment** *(01: DC Cut HPF Input2-SL, 10: DC Cut HPF Input3-L, 11: Prohibited)* |
| **[5:4]** | **SR Volume Input Selector** | **`00`** | **SL X'over** *(01: DC Cut HPF Input2-SR, 10: DC Cut HPF Input3-R, 11: Prohibited)* |
| **[3:2]** | Reserved | `00` | Фіксовано `0` |
| **[1]** | **Digital Mixing Stereo Mix** | **`0`** | **Monaural (L)** |
| **[0]** | **Digital Mixing Input Selector** | **`0`** | **DC Cut HPF (Input3-L/R)** |

### 2.2. Регістр `0102` (Select Address `0x0102` / Fader Input Selector)
* **Розташування в Flash таблиці мапінгу**: `0x0800D00F` (індекс `28` у таблиці `0x0800CFD7`).
* **Адреса в SRAM тіньовому буфері**: `0x200000E2 + 28 = 0x200000FE`.
* **Значення в прошивці**: **`0x00` (`00000000b`)**.

| Біти | Поле | Значення | Розшифровка за даташитом BU32107 |
|:---:|:---|:---:|:---|
| **[7:6]** | Reserved | `00` | Фіксовано `0` |
| **[5:4]** | **Sub Selector** | **`00`** | **SL / SR** *(01: RL / RR, 10: SL / SL, 11: Prohibited)* |
| **[3:2]** | Reserved | `00` | Фіксовано `0` |
| **[1:0]** | **Rear Selector** | **`00`** | **RL / RR** *(01: FL / FR, 10: Monaural(FL+FR), 11: Prohibited)* |

## 3. Перевірка коду прошивки MCU (Provenance & Disassembly)

### 3.1. Розпакування початкового стану `.data` (Power-On Reset)
При старті MCU функція `FUN_08005FF0` викликає декомпресор `FUN_08003D7C`, який розпаковує стиснений блок із Flash `0x0800F5D0` в SRAM `0x200000C0` (розмір 364 байти).

Тіньовий масив регістрів BU32107 займає діапазон `0x200000E2`..`0x20000162`:
```
0x200000E0: 00 00 [10 00 00 00 00 00 00 00  00 00 00 00 00 00 00 00]
0x200000F0: [00 00 00 00 00 00 00 00 00 00  00 00 00 00 00 00 00 00]
                                              ^^ 0x200000FE = Reg 0102 = 0x00
0x20000100: [00 00 00 00 00 00 00 00 00 00  00 00 00 00 00 00 00 00]
                                              ^^ 0x2000010D = Reg 0206 = 0x00
```

### 3.2. Аудит обробників команд UART (Runtime Handlers)
Було проведено повний аудит усіх модифікацій масиву `0x200000E2..0x20000162`:

| Команда UART | Функція MCU | Модифіковані адреси SRAM | Відповідні регістри BU32107 |
|---|---|---|---|
| `0x80` (Mute/Vol) | `FUN_080054F0` | `0x2000020B`, `0x2000020C` | Змінні гучності фейдера |
| `0x88` (Loud/Sub) | `FUN_080053BC` | `0x20000134`, `0x20000132`, `0x20000155` | `0707` (Sub LPF/HPF), `0705` (P2Bass), `0A04` (Sub Fader Vol) |
| `0x89` (EQ 16-band)| `FUN_080052C8` | `0x20000121` .. `0x20000130` | `0610` .. `061F` (Front EQ Gains) |
| `0x8A` (HPF) | `FUN_08005260` | `0x20000131` | `0704` (Front/Rear HPF) |
| `0x8B` (Bal/Fader)| `FUN_080051EC` | `0x20000151` .. `0x20000154` | `0A00` .. `0A03` (FL/FR/RL/RR Analog Fader) |
| `0x8C` (Time Align)| `FUN_08005080` | `0x20000110` .. `0x2000011D` | `0400` .. `040D` (Time Alignment Delays) |

**Результат аудиту**: Адреси `0x200000FE` (Reg `0102`) та `0x2000010D` (Reg `0206`) **не записуються жодною рантайм-функцією**. Вони стабільно дорівнюють `0x00`.

```

             │
             ▼

             ▼

             │
             ├──────────────────────────────────────────────────────┐
             │                                                      │
```

## 5. Архітектурні висновки для wDSP

1. **Кросовер сабвуфера знаходиться ПІСЛЯ еквалайзера**:
   Сигнал сабвуферного тракту повністю проходить крізь 16-смуговий параметричний EQ. Зміна посилення на смугах 20, 31.5, 50, 80 Гц в еквалайзері безпосередньо модулює рівень вхідного сигналу на кросовері сабвуфера.
2. **Усунення подвійного підйому (Double Boosting)**:
   При реалізації алгоритму `Dynamic Loudness` збільшення посилення низьких частот через таблицю EQ автоматично компенсує втрату чутливості людського слуху і для сабвуфера.
3. **Призначення `Subwoofer Gain Offset`**:
   Збільшувати параметр `Subwoofer Gain` (MCU команда `0x88` / регістр `0A04`) має сенс лише як "overflow headroom" — у випадку, коли необхідний рівень тонкомпенсації перевищує максимальну межу еквалайзера `+12 dB`.

  `0x8C` — затримки. Отже «аудит усіх обробників: `0206` не пише ніхто» НЕ підтверджено; висновок тримається на
  значенні після скидання і на `platform/03-SOUND-PROCESSOR.md` §5.

  кросовером. Остаточний доказ — акустичний: +6 дБ у смузі 31.5 Гц на скретч-пресеті, чи виріс вихід саба (борг тестів).
